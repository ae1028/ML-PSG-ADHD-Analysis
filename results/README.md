# Results

This directory separates the scientific study record from software-demo
outputs.

## Canonical published performance metrics

The study reports average classification performance of:

| Metric | Published value |
| --- | ---: |
| Accuracy | 0.72 |
| Precision | 0.71 |
| Recall | 0.85 |
| F1 score | 0.76 |

The machine-readable form is:

`published_performance_metrics.csv`

These values are treated as the publication record.

They are not regenerated from the public synthetic demonstration.

## Study characteristics

The study included:

- 48 participants;
- 25 participants in the ADHD group;
- 23 control participants;
- ages 6 to 18 years.

The analysis included:

- 20,294 ADHD epochs;
- 19,968 control epochs;
- 30-second PSG epochs;
- sampling at 512 Hz;
- 17 PSG channels.

The 17 channels comprised:

- 8 EEG channels;
- 2 EOG channels;
- 5 EMG channels;
- 2 ECG channels.

See:

`published_study_characteristics.csv`

## Scientific provenance

The canonical scientific record is distinct from generated repository
outputs.

### Published results

Values explicitly reported as part of the study are stored here as
published-result records.

### Historical implementation

The original implementation is preserved under:

`reference_implementations/published_pipeline/`

The preserved scripts establish historical computational behavior but
do not by themselves guarantee regeneration of one exact historical
numerical run.

### Synthetic demonstration

Outputs generated by:

`python scripts/run_synthetic_demo.py`

are software-test artifacts only.

Synthetic accuracy, precision, recall, F1, feature importance, or graph
feature values must never be cited as results from the ADHD study.

## Numerical reproduction boundary

The standalone historical modeling implementation contains unseeded:

- augmented-data shuffling;
- outer KFold shuffling;
- Random Forest fitting.

Therefore exact numerical replication of one historical execution cannot
be guaranteed from the source code alone.

The repository distinguishes:

1. publication-record preservation;
2. historical behavioral reconstruction;
3. exact numerical reproduction.

The first two are represented in this repository.

Exact numerical reproduction requires the applicable original research
inputs and historical stochastic state.

## Feature-importance results

The historical source calculates both:

- Random Forest impurity-based feature importance;
- permutation importance.

However, this repository does not invent or infer canonical numerical
importance values when an authoritative numerical record has not been
established.

Any future addition of numerical feature-importance results should be
traceable to a preserved authoritative result artifact.
