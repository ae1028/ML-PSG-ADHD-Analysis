# Study Results

This document summarizes the canonical study-level results represented
by this repository.

## Classification performance

The reported average Random Forest classification performance was:

| Metric | Value |
| --- | ---: |
| Accuracy | 0.72 |
| Precision | 0.71 |
| Recall | 0.85 |
| F1 score | 0.76 |

These values represent the published study record.

They must not be replaced by numbers generated from the public synthetic
demonstration.

## Study cohort

The study included 48 participants between 6 and 18 years of age:

- 25 ADHD participants;
- 23 controls.

The processed epoch counts were:

- 20,294 ADHD epochs;
- 19,968 control epochs.

## PSG representation

The study used 17 PSG channels:

- 8 EEG;
- 2 EOG;
- 5 EMG;
- 2 ECG.

Signals were represented using 30-second epochs sampled at 512 Hz.

## Sleep-stage graph biomarkers

The analysis considered five stage-level participant features:

1. Wake;
2. Sleep Stage 1;
3. Sleep Stage 2;
4. Sleep Stage 3-4;
5. Rapid Eye Movement.

For each participant-stage combination, the reconstructed historical
workflow:

1. calculates Pearson channel correlations for each epoch;
2. takes absolute correlation values;
3. averages epoch adjacency matrices;
4. constructs a weighted NetworkX graph;
5. calculates weighted shortest paths using correlation itself as the
   edge weight;
6. averages the returned shortest-path values into one stage-level
   feature.

The five stage features form the participant-level representation used
by the historical machine-learning workflow.

## Modeling workflow

The standalone historical modeling script performs sign-inversion
augmentation before nested cross-validation.

The historical Random Forest parameter grid contains:

- `n_estimators`: 100, 200, 300;
- `max_depth`: 10, 20, 30;
- `min_samples_split`: 2, 5, 10;
- `min_samples_leaf`: 1, 2, 4.

The inner GridSearchCV uses five folds and refits according to accuracy.

The outer evaluation uses five-fold KFold.

## Important reproduction limitation

The standalone historical implementation did not assign explicit random
seeds to:

- augmented-data shuffle;
- outer KFold;
- Random Forest classifier.

Consequently, exact numerical regeneration of one historical run is not
guaranteed.

The published metrics in this repository should therefore be understood
as preserved publication-record values, not outputs claimed to have been
deterministically regenerated by the cleaned implementation.
