## Repository relationship to the paper

This repository preserves and reconstructs the computational workflow
associated with the study.

The repository contains:

- exact preserved historical source implementations;
- cleaned and tested reusable implementations;
- historical modeling configuration;
- synthetic public demonstration data;
- machine-readable publication-result summaries;
- reproducibility and methodological limitation documentation.

The original protected participant-level PSG recordings are not
distributed.
