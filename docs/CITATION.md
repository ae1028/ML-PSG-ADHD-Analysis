## Repository versus paper citation

The repository and publication serve different purposes.

The repository provides:

- preserved historical source implementations;
- cleaned reusable software;
- automated tests;
- historical configurations;
- synthetic public demonstrations;
- reproducibility documentation;
- canonical result records.

The associated IEEE ISBI paper is the authoritative scientific
publication describing the study.

## Data citation boundary

The original participant-level PSG data are not publicly distributed
through this repository.

The synthetic example data under `examples/` are software demonstration
artifacts and must not be cited as a clinical dataset or as the original
study data.
