# Limitations

This repository reconstructs a research workflow developed for a
specific polysomnography-based ADHD analysis study.

Important limitations and boundaries will be documented here,
including:

- limited study sample size;
- dependence on the original PSG acquisition and annotation process;
- unavailable raw clinical data in the public repository;
- research-only interpretation of model performance;
- distinction between reproducibility of code and reproducibility of
  the complete clinical experiment;
- known historical implementation and publication discrepancies that
  require transparent documentation.

The repository must not be interpreted as a clinical diagnostic tool.
